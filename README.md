# This mod requires Fika and will *not* work without it
Adds back the superior DynamicAI from the Fika plugin that was removed with 4.0, enabling you to get even greater performance while hosting. AI that are further away than the set range will be disabled, increasing performance.

Only the raid host needs the mod, and it's completely useless as a client.
